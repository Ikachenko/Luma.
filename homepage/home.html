User Data

We use the chrome.storage API to store user preferences. We do not collect private information nor do we share data with other 3rd party entities beyond Ikachenko (as an author) and Google.

Types of Information stored:

  • Install date
  • Pinned applications
  • Settings

Data removal:

If you wish to remove your data, you can do so by clicking the button below or by uninstalling the extension. This action will erase all current data and preferences. Changes cannot be reverted.
